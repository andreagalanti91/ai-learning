Capitolo 02 · Livello 1 · Prompt

Il framework BRIEF

BBackground: il contesto
RRuolo: chi deve rispondere
IIntento: cosa serve davvero
EEsempi: come deve essere
FFormato: in che forma

Più la verifica finale. Dal prompt semplice al brief, con un esempio "prima e dopo" dello stesso compito.

Capitolo 08 · Percorsi per ruolo (1/2)

Base → Intermedio → Avanzato

8.1 Marketing

  • Base: testi, post, varianti di copy, adattamento del tono
  • Intermedio: Project con brand e tono, piano editoriale, analisi competitor con ricerca web
  • Avanzato: Skill del tono di voce, campagne con Claude Design, report da dati Excel o CSV

8.2 Project Management

  • Base: verbali, email ai clienti, riassunti di documenti
  • Intermedio: Project per cliente, stime, rischi, timeline, status report
  • Avanzato: connettori Drive e Notion, Skill per gli status report, attività programmate, dashboard di progetto

8.3 UX/UI e Product Design

  • Base: sintesi di interviste, personas, microcopy
  • Intermedio: user journey, architettura dell'informazione, analisi euristica da screenshot
  • Avanzato: design system e token via Figma MCP, prototipi, handoff a Claude Code, revisione di accessibilità

Capitolo 08 · Percorsi per ruolo (2/2)

Base → Intermedio → Avanzato

8.4 Art Direction e Graphic Design

  • Base: concept, moodboard testuali, naming, claim
  • Intermedio: brief creativi, analisi di riferimenti visivi, varianti di layout
  • Avanzato: Claude Design per visual e one-pager, brand kit come contesto, export verso Canva, prompt per AI generative di immagini

8.5 Sviluppo

  • Base: spiegare codice, snippet, regex, query
  • Intermedio: debug, test, documentazione, code review
  • Avanzato: Claude Code con CLAUDE.md, subagent, GitHub, Figma MCP da design a codice, automazioni
