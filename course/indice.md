# CLAUDE AI — FROM PROMPTING TO BUILDING

**Indice del corso · Bozza v0.2 · UX Boutique**

> Contesto: 6 partecipanti (marketing, PM, design, art direction e grafica, sviluppo) · piano Claude Team per tutti · account Figma di team · 2 giornate da 4 ore, da remoto.

## 08 — Percorsi per ruolo: dalle basi all'uso avanzato
Per ogni ruolo: **Base** → **Intermedio** → **Avanzato**.

- **8.1 Marketing**
  - Base: testi, post, varianti di copy, adattamento del tono
  - Intermedio: Project con brand e tono, piano editoriale, analisi dei competitor con ricerca web
  - Avanzato: Skill del tono di voce UX Boutique, campagne complete con Claude Design, report sulle performance da dati Excel o CSV
- **8.2 Project Management**
  - Base: verbali, email ai clienti, riassunti di documenti
  - Intermedio: Project per cliente, stime, rischi, timeline, status report
  - Avanzato: connettori Drive e Notion, Skill per gli status report, attività programmate, dashboard di progetto
- **8.3 UX/UI e Product Design**
  - Base: sintesi di interviste, personas, microcopy
  - Intermedio: user journey, architettura dell'informazione, analisi euristica da screenshot
  - Avanzato: design system e token via Figma MCP, prototipi con Claude Design, handoff a Claude Code, revisione di accessibilità
- **8.4 Art Direction e Graphic Design**
  - Base: concept, moodboard testuali, naming, claim
  - Intermedio: brief creativi, analisi di riferimenti visivi, varianti di layout
  - Avanzato: Claude Design per visual e one-pager, brand kit come contesto, export verso Canva, prompt per AI che generano immagini
- **8.5 Sviluppo**
  - Base: spiegare codice, scrivere snippet, regex, query
  - Intermedio: debug, test, documentazione, code review
  - Avanzato: Claude Code con CLAUDE.md, subagent, GitHub, Figma MCP da design a codice, automazioni
